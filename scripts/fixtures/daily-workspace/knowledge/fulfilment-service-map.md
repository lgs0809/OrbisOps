# 仓配履约服务与数据契约

本资料是本机合成场景，没有真实仓库、运单或客户信息。

仓库出库创建与查询任务，物流事件接收运单状态，履约追踪整理订单与履约进度。三项服务共享 fulfilment-store。观察台账中的重复 request_key 表示事件重放，不能视为再次出库。

只读数据源含 service_inventory、request_observation、service_dependency、service_configuration 与 change_window。样本区间固定为 2026-09-29 至 2026-10-08；历史合成观察不能证明当前任务积压或服务可用性。

物流事件可能重复或乱序。收到“已发货”事件不代表所有关联订单已完成，也不能自动推进更早或更晚的业务状态。应保留事件原始时间、收到时间、去重身份以及前后状态证据。

出库、状态推进和事件重放均须遵守原有业务幂等与审批边界；当前日常只读工作空间不会预先授予写权限。
