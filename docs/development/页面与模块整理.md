# 页面与模块整理

2026-10-03。本批调整页面体验和前端职责，保留现有项目权限、生产审批、版本绑定和自然语言入口。后端仍运行部署17；当前 Java 工作区候选和完整回归缺项见[当前开发状态](OrbisOps-当前开发状态.md)。

## 工作空间

八个一级入口统一使用同一导航和页头：对话、首页、工作台、工作流、自动化、项目、变更、设置。桌面默认展开导航，中等宽度收起为图标，窄屏使用覆盖抽屉；Escape、遮罩和选中页面均可关闭抽屉。子页面的当前入口保持高亮，桌面可返回所属目录。

对话、工作台、工作流编辑、项目和设置使用共同的剩余高度容器。页面只保留一个 `main`，滚动由工作区内部负责。窄屏表单按列排列，表格保留内部横向滚动；完整证据按需展开，不缩短真实审批内容。

首页和工作流在读取数据时明确显示加载状态，读取失败提供重试，不把缺数据呈现为零事件或健康。项目选择器保持权限过滤后的身份列表；项目管理页另外读取已有完整管理投影，避免把简化身份对象误当完整资源配置。

## 职责归属

| 位置 | 职责 | 保留的边界 |
| --- | --- | --- |
| `web/src/app/navigation/route-metadata.ts` | 注册路径、标题、所属目录和可见角色 | 页面不另造路由或角色表 |
| `components/layout/Sidebar.tsx`、`Sidebar.styles.ts` | 导航交互和响应式样式分别维护 | 原退出、账号、角色筛选沿用 |
| `components/layout/Header.tsx` | 当前页标题、导航按钮和返回父目录 | 返回设置保留分类参数 |
| `components/ops-layout/OpsPageShell.tsx`、`OpsWorkspaceFrame.tsx` | 公共页面高度、单一主区域、侧栏与内部滚动 | 功能页不再重复计算视口高度 |
| `features/platform/model/settings-navigation.ts` | 设置分类说明与查询参数校验 | 路由及权限仍引用中央注册表 |
| `features/projects/api/project-workspace-queries.ts` | 管理页完整投影和能力查询 | 完整投影限管理页及管理账号，选择器不扩大权限 |
| `features/projects/model/project-product-navigation.ts` | 项目页标签与高级入口默认视图 | 无效标签返回安全默认值 |
| `features/changes/components/ChangePackageList.tsx` | 变更列表展示、受控回调 | 查询、审批和落地动作仍由原页面/服务处理 |
| `features/changes/model/change-package-summary.ts` | 目标、摘要及编号的展示顺序 | 不派生审批或执行成功 |
| `pages/workflow-builder.tsx`、`components/ops-agent-canvas.tsx` | 工作流配置、节点画布和缩放 | 发布/执行合同未变；嵌入画布使用父容器高度，独立画布保留默认高度；节点工具不覆盖画布，短/窄视区收起小地图 |
| `styles/theme.ts`、`global.ts` | 颜色、文字对比度、焦点、表单和表格密度 | 业务状态继续来自真实 DTO |

业务页保留组合职责，领域查询、模型和纯展示放入对应 `features`。本批没有为了移动文件而改造后端模块，也不将未完成后端候选包装成新的可部署版本。

## 人工复查入口

在现有隔离环境打开 `http://127.0.0.1:3302`，使用原有账号；凭据在忽略的私有部署目录，不进入文档。

1. 首页等待实际数据，进入工作台和事件；导航菜单高亮应跟随当前模块。
2. 工作流按名称搜索已有流程，打开编辑。名称、说明和节点能力可编辑；本批只临时输入后恢复，没有保存、发布或重跑业务。
3. 现有已发布工作流的“测试 → 打开对话手动执行”会创建绑定版本的空会话。直接用自然语言输入；未发送前不会启动模型或工具。本批原生数据库复核为 v2、`PINNED_VERSION`、消息数0。
4. 变更进入“需要处理”，打开原失败包。核对版本/hash、批准范围、唯一写回执、原失败和事件轨迹；本批没有重试 Landing、清理或复核写动作。
5. 设置切换“智能能力”，打开模型，再返回设置；分类保留在地址和按钮选中状态。项目高级入口默认打开执行资源。
6. Chrome 窄屏375×812：打开/关闭导航，检查表单、内部表格滚动，滚至画布后使用适应视图、放大和缩小。结束恢复浏览器原尺寸。

完整路由和截图见[页面体验验收](../acceptance/2026-10-03-页面体验验收.md)。这些检查证明界面可用，不代替模型质量、十五分钟 SLO、TaskAcceptance 或 Skill 进化的业务验收。
