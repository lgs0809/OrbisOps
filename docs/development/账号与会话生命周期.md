# 账号与会话生命周期

账号由管理员添加，使用手机号和密码登录。姓名用于显示，内部用户 ID 用于权限和任务归属；手机号变更不会重新生成身份。没有公开自助注册。平台角色与项目角色独立。

## 初始密码、修改与重置

新账号创建时，将初始密码的 BCrypt 值分别保存为初始凭据和当前凭据，标记 `passwordChangeRequired=true`。登录仍发放个人会话，允许读取自身资料、修改自身密码和退出；其余业务请求由统一服务端权限拦截器拒绝，页面同步引导到密码设置页。

用户提交当前密码和新密码后，应用用例验证当前凭据、密码强度及不能复用当前或初始密码。MySQL 在同一条带版本条件的更新中保存新凭据、解除首次修改标记并增加凭据版本。随后发放新会话。

管理员重置只恢复创建时存储的初始加密值，重新开启首次修改标记并增加版本。接口不返回明文或加密值，也不让管理员替用户指定新的个人密码。初始密码应在创建时通过安全渠道交给成员；系统不提供取回明文的入口。

JWT 绑定凭据版本；每次鉴权查询当前账号状态、角色及版本。修改或重置后的旧令牌立即失效，不需要等原令牌过期。并发修改和重置使用乐观版本比较，只有一个请求提交；后到的请求要求刷新或重新登录。正常注销仍依赖持久撤销记录确认，不在撤销存储故障时宣称成功。

## 代码职责

- 领域账号保存身份、初始凭据、当前凭据、首次修改标记及版本。
- `AdminCredentialLifecycleUseCase` 管理自助修改与管理员重置规则；仓储端口提供带版本的原子操作。
- MyBatis 适配器负责更新及行数确认，入口只从已认证主体获取个人身份，忽略请求中试图指定的其他用户身份。
- Spring 统一权限拦截器严格区分个人接口和管理员接口，普通用户不能调用重置、创建或用户目录接口。
- React / TanStack Query 负责读取、提交和刷新；保存中的重复提交被禁止，卸载或换账号后的迟到响应不会恢复旧会话。
- 统一 HTTP 层只清除与失败请求属于同一令牌的会话，旧请求的迟到401不会清除密码更新后的新会话。

## 迁移与旧账号

迁移103增加三个字段，已有账号不更改密码、不启用强制首次修改，版本默认为0。迁移102的手机号、内部身份和原关联保持。旧 JWT 未携带版本时按0处理，并仍核对数据库中的版本。

旧账号没有创建时的初始凭据，无法恢复一个不存在的初始密码；接口拒绝此类重置，不能静默设置通用密码。旧账号可以继续通过原账号入口登录、绑定手机号并使用自助修改。新建展示环境使用完整的新账号生命周期。

## 验证范围

回归包含迁移重复执行及旧行保持、真实 MySQL 下初始登录→自助修改→管理员重置、两请求竞争更新、旧 JWT 立即失效、强制首次修改时的接口边界、普通用户退出和 UI 失败/重复/迟到响应。实际部署另通过正常 HTTP 接口与浏览器核对，并在交付前把三个展示账号恢复到首次修改状态。历史展示数据与模型或资源执行验收分别记录。
