## 实现边界

Evolution 使用专用元数据 SQL 排序，再读取最多 5 个关联 Skill 的完整正文和资源。项目目录与平台文件目录按作用域合并，同身份优先数据库条目。旧目录 API 保持兼容；本批没有把普通运行时召回改成 ANN，该部分仍属于 OPS-07。

同一提案保存完整关联包、版本、Skill／Package Hash、目录与治理状态指纹。作者只能引用冻结项目中的目标；平台、内置和仅人工维护方法不能自动改写。候选落库时，锁定目录及资源，复核正文、资源字节、版本和治理状态，目标必须匹配已保存的作者响应。数据库覆盖文件条目也会撤销旧引用。文件目录由当前部署的 SDK 加载，应用在生成及匹配前重查所选文件的指纹；它不是独立文件系统分布式事务。

重试优先读取原提案及作者结果，避免重新读取另一批关联版本；无法满足校验时保留失败原因。作者固定 gpt-5.6-terra，提示版本为 `skill-author-related-packages-v2`；Luna／Terra 选型没有替换。生成器没有执行工具权限。成功来源和关联 Skill 是方法生成输入，不是独立行为验收题。
