```sh
python3 scripts/inspect-skill-publication-acceptance.py --output /tmp/orbisops-file-projection.json
```

迁移 085～087 只创建运行可见版本、预算和文件来源投影表。部署器更新已测试 JAR 与迁移清单，重连隔离 MCP，保留全部旧业务记录。配置文件型 Skill 每轮最多投影 100 个；后台周期会补齐，未投影的文件不会走运行态旁路。人工资产同名时优先，用户修改已有导入版本后由用户管理，文件导入器不覆盖它。

内置 Skill 初始化仅升级与旧内置文件完全一致的可编辑副本，通过正常更新 API 留下配置审计；重复执行跳过已更新文件，用户修改过或不可读的文件保留。升级时不要同时编辑同一文件，现有文件 API 没有跨进程 CAS 契约。后台投影间隔 60 秒，等待一轮后再执行检查。

## 实现边界与预算格式

Qwen 端点已配置时，运行选择只读取 MySQL 中已激活的可见版本。后台先保存不可变 PG READY 向量，再校验对应 MySQL 版本正文、manifest 和全部 artifact 的 hash，最后提交可见指针。任一步骤中断都会保留旧指针，后续扫描重试。两库没有分布式事务；READY 代际不可变，未激活的新版本不进入运行词法/语义候选。当前隔离环境未配置 Qwen 端点，继续使用已约定的文本降级，不能把合成向量测试称为真实 Qwen 检索成功。

正文预算以 UTF-8 字节数作保守 token 上界，最多 6000，最多 3 份版本；不是供应商返回的实际 token 用量。配置中的旧字符限制作为额外保守上限。必需正文完整保留，超限报错，不截掉末尾安全要求。目录每条最多 300 个同类估算单位，完整条目放不下则不注入该条摘要。

超长正文可以把**经审阅确认可省略**的示例等章节显式标注为可选模块：

```markdown
必需的前提、权限、核心规程和验证要求放在标记之外。
<!-- orbisops:optional id=log-example keywords=日志|logs -->
一个完整的可选日志示例。
<!-- /orbisops:optional -->
所有场景都必须遵守的安全约束仍放在标记之外。
```

只对任务关键词匹配、且完整模块放得下的模块加载。不自动猜测普通 Markdown 的哪些段落可省略。资源按绑定版本加载，入口前提一并提供；二进制只显示元信息，评测资产不进入日常模型上下文。同一个 Run 的节点、重试及恢复共用持久化预算；重复相同版本/正文不重复计入，换版本或读取额外资源继续占用额度。这是选中正文与资源的去重预算，不是整段多轮聊天的总 token 预算。

## 自动化回归

```sh
mvn -B -f server/pom.xml '-Dtest=SkillRuntimePublicationMySqlPgTest,SkillRuntimeBodyPolicyTest,OpsRuntimeSkillResolverTest,OpsRuntimeResourceAssemblerTest,OpsSkillCatalogExecutionDispatchHandlerTest,SkillCatalogReadServiceTest,RuntimeSkillResourceBoundaryArchitectureTest,SkillCatalogTypedBoundaryArchitectureTest,SkillNarrowInterfaceArchitectureTest,SpringComponentConstructorArchitectureTest,OpsMigrationManifestTest' -Dsurefire.failIfNoSpecifiedTests=false test
```

`SkillRuntimePublicationMySqlPgTest` 使用绑定回环地址的独立 MySQL 与 PG Testcontainers，数据是显式合成包及单位向量；覆盖半发布、重试、损坏正文、并发发布、撤权、文件版本、人工资产保护、事务失败回滚、预算并发与重建实例后的持久性。
